연결 확인 중… backend 상태

행정동을 고르면 그 동만, 비워두면 선택한 시·군·구(또는 시·도) 전체를 표본으로 분석합니다.

Getting Started

지역 또는 반경을 고르고 분석하기를 눌러보세요

왼쪽 위 탭에서 "지역으로 찾기"(시·도 → 시·군·구 → 행정동) 또는 "반경으로 찾기"(즐겨찾는 위치 또는 좌표 직접 입력)를 고른 뒤, 필요하면 업종을 좁히고 분석하기를 누르세요.

데이터 안내. 소상공인시장진흥공단 상가(상권)정보 OpenAPI(공공데이터포털, data.go.kr)를 백엔드가 대신 호출해 보여줍니다. 데이터는 분기별로 갱신되며 국세청 사업자등록 정보를 기반으로 하기 때문에, 최근 개업·폐업이 반영되기까지 시차가 있을 수 있습니다. 반경분석은 API 제한상 최대 2,000m까지만 가능하고, 지역·반경이 너무 넓으면 표본을 최대 5,000건까지만 가져와 집계합니다(그 이상은 "표본 기준" 안내가 뜹니다). 위치 분포는 네이버 지도 위에 표본 전체를 표시합니다. 지도 키가 없거나 인증에 실패하면 좌표 상대 위치를 보여주는 산점도로 대체됩니다. "업종 쏠림"은 상위 3개 소분류가 표본에서 차지하는 비율로, 값이 높을수록 특정 업종에 집중된 상권입니다.
